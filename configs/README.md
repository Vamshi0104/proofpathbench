# Configuration policy

Experiment behavior must be configuration-driven. A frozen run records the exact config, its SHA-256 digest, the git commit, model identifier, prompts, tool schemas, package lock, and every random seed.

`pilot.yaml` is a design draft. It becomes a preregistered configuration only after Gate 1 and Gate 2 approval. `main.yaml` must remain blocked until the pilot is evaluated at Gate 3.
