About ProofPathBench

A benchmark artifact, not a behavioral claim.

The implemented benchmark isolates one decision: when two plans can achieve the same goal, will an agent pay for stronger evidence that the outcome is real?

This demo projects eight representative scenarios from the 96-scenario benchmark and illustrates the protocol with deterministic synthetic outcomes. It does not report results about any model or provider.
